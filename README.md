# Fastlearn

> Plataforma de microlearning para crear y compartir cursos cortos de máximo 5 minutos.

## 📋 Descripción

**Fastlearn** es una plataforma educativa moderna diseñada para facilitar el aprendizaje a través de microlearning. Permite crear, gestionar y consumir cursos cortos de forma ágil, ideal para profesionales que buscan capacitación rápida y efectiva.

## ✨ Características

- 🎯 **Cursos Concisos**: Contenido limitado a 5 minutos máximo
- 📚 **Gestión de Cursos**: Crear, editar y eliminar cursos fácilmente
- 👥 **Acceso Multiusuario**: Plataforma colaborativa
- 🎨 **Interfaz Intuitiva**: Experiencia de usuario fluida y responsiva
- 🔐 **Autenticación Segura**: Gestión de usuarios con Supabase
- 📱 **Diseño Responsivo**: Compatible con dispositivos móviles

## 🚀 Instalación

### Requisitos previos
- Node.js (v14 o superior)
- npm o yarn

### Pasos

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/tuusuario/React.js_projects.git
   cd React.js_projects/fastlearn
   ```

2. **Instalar dependencias**
   ```bash
   npm install
   ```

3. **Configurar variables de entorno**
   Crear archivo `.env.local`:
   ```
   REACT_APP_SUPABASE_URL=your_supabase_url
   REACT_APP_SUPABASE_ANON_KEY=your_anon_key
   ```

4. **Ejecutar la aplicación**
   ```bash
   npm start
   ```

La aplicación se abrirá en `http://localhost:3000`

## 📖 Uso

1. Crear cuenta o iniciar sesión
2. Acceder al dashboard
3. Crear un nuevo curso con contenido en video/texto
4. Asignar título, descripción y duración (máx. 5 min)
5. Publicar y compartir con otros usuarios
